# Twitch Volume Balance

Twitch の配信者ごとの音量差を、チャンネル別の補正値として記憶する Chrome 拡張です。

## 機能

- チャンネルごとに 0〜200% の音量補正を保存
- Twitch 内で別チャンネルへ移動したときも自動で設定を切り替え
- `twitch.tv/videos/動画ID` 形式のアーカイブでも配信者を検出して同じ設定を適用
- Twitch の画面構成が変わって配信者を検出できない場合も、アーカイブ専用設定として利用可能
- 100% を超える音量は Web Audio API で増幅
- 増幅時の急なピークを抑えるリミッター
- 補正中の出力レベルをリアルタイム表示
- キーボードショートカットで補正値を操作
- Chrome Sync による端末間の設定同期
- 設定を JSON で書き出し・読み込み
- 保存済みチャンネルの一覧と削除
- Twitch 以外のサイトでは動作しない最小権限構成

## Chrome への読み込み

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」を選ぶ
4. このフォルダーを選択する
5. すでに Twitch を開いていた場合は、そのタブを再読み込みする

ZIP から導入する場合は、ZIP を展開してから手順 3 以降を行います。開発環境では `npm install` 後に `npm run package` を実行すると、`release/` に導入用 ZIP を生成できます。

## 使い方

1. Twitch で配信ページを開く
2. ツールバーの拡張機能アイコンを押す
3. スライダーで聞きやすい音量に調整する

設定は現在のチャンネル名に紐づけて保存されます。Twitch 自体の音量スライダーは基準音量として、そのまま併用できます。

設定は Chrome Sync に保存されます。旧バージョンのローカル設定がある場合は、最初の起動時に自動で移行されます。保存済み一覧から JSON バックアップの書き出しと読み込みができます。

## キーボードショートカット

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 補正を5%上げる | `Alt+Shift+↑` | `Command+Shift+↑` |
| 補正を5%下げる | `Alt+Shift+↓` | `Command+Shift+↓` |
| 100%に戻す | `Alt+Shift+0` | `Command+Shift+0` |
| 有効・無効を切り替える | `Alt+Shift+M` | `Command+Shift+M` |

ショートカットは `chrome://extensions/shortcuts` から変更できます。

## 注意

- 100% を超える増幅は音割れの原因になるため、まず Twitch 側の音量を適度に下げてから補正してください。
- 他の音声加工系拡張が同じ動画に Web Audio API を接続している場合、同時に利用できないことがあります。
- Twitch 側のプレイヤー実装が変更された場合は、再読み込みや拡張機能側の更新が必要になる可能性があります。
- アーカイブで配信者を検出できない場合は、5秒後にその動画専用の設定へ切り替わり、ポップアップに警告を表示します。検出経路は開発者ツールのコンソールで確認できます。
